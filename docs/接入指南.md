# Gemini Web To API — 接入指南

> 服务器：`api.xiaoyekanren.com`（HTTPS，已配置 nginx 反代 + SSL 泛域名证书）
> 基础 URL：`https://api.xiaoyekanren.com`

## 1. 前置条件

### 1.1 DNS 解析（一次性）

需在域名管理后台添加一条 A 记录：

| 类型 | 主机记录 | 记录值 |
|------|---------|--------|
| A | api | 82.157.206.59 |

### 1.2 配置 Cookie（一次性）

1. 浏览器访问 https://gemini.google.com 并登录 Google 账号
2. F12 → Application → Storage → Cookies → `gemini.google.com`
3. 复制 `__Secure-1PSID` 和 `__Secure-1PSIDTS` 的值

然后 SSH 到服务器，填入 `.env`：

```bash
ssh ubuntu@xiaoyekanren.com
sudo vim /opt/gemini-web-to-api/.env
```

修改这两行：

```
GEMINI_1PSID=你复制的_1PSID值
GEMINI_1PSIDTS=你复制的_1PSIDTS值
API_KEY=生成一个随机字符串作为API密钥
```

### 1.3 启动服务

```bash
sudo systemctl enable gemini-web-to-api
sudo systemctl start gemini-web-to-api
sudo systemctl status gemini-web-to-api
```

## 2. 各客户端接入方式

所有客户端共享同一个 API Key（`.env` 中 `API_KEY` 的值，下文中用 `<YOUR_API_KEY>` 表示）。

---

### 2.1 Claude Code

编辑 `~/.claude/settings.json`（Windows 路径 `C:\Users\<用户名>\.claude\settings.json`），修改 `env` 部分：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.xiaoyekanren.com/claude",
    "ANTHROPIC_AUTH_TOKEN": "<YOUR_API_KEY>",
    "ANTHROPIC_MODEL": "gemini-2.5-pro",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "gemini-2.5-pro",
    "ANTHROPIC_DEFAULT_OPUS_MODEL_NAME": "gemini-2.5-pro",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "gemini-2.5-flash",
    "ANTHROPIC_DEFAULT_SONNET_MODEL_NAME": "gemini-2.5-flash",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "gemini-2.5-flash",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL_NAME": "gemini-2.5-flash"
  }
}
```

> **说明**：Claude Code 使用 Anthropic 协议。`ANTHROPIC_BASE_URL` 指向 `/claude` 基础路径，SDK 自动拼接 `/v1/messages`。`ANTHROPIC_AUTH_TOKEN` 以 `x-api-key` header 发送，与本项目的 API Key 校验对齐。

### 2.2 OpenAI SDK / 兼容客户端

**base_url**：`https://api.xiaoyekanren.com/openai/v1`
**api_key**：`<YOUR_API_KEY>`
**model**：`gemini-2.5-pro` 或 `gemini-2.5-flash`（通过 `/openai/v1/models` 查看可用列表）

#### Python (openai 库)

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.xiaoyekanren.com/openai/v1",
    api_key="<YOUR_API_KEY>"
)

response = client.chat.completions.create(
    model="gemini-2.5-pro",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
```

#### Python (流式)

```python
stream = client.chat.completions.create(
    model="gemini-2.5-pro",
    messages=[{"role": "user", "content": "写一首诗"}],
    stream=True
)
for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
```

#### Node.js (openai 库)

```js
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.xiaoyekanren.com/openai/v1",
  apiKey: "<YOUR_API_KEY>",
});

const response = await client.chat.completions.create({
  model: "gemini-2.5-pro",
  messages: [{ role: "user", content: "Hello!" }],
});
console.log(response.choices[0].message.content);
```

#### cURL

```bash
# 非流式
curl -X POST https://api.xiaoyekanren.com/openai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "x-api-key: <YOUR_API_KEY>" \
  -d '{
    "model": "gemini-2.5-pro",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

# 流式
curl -X POST https://api.xiaoyekanren.com/openai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "x-api-key: <YOUR_API_KEY>" \
  -d '{
    "model": "gemini-2.5-pro",
    "messages": [{"role": "user", "content": "Hello!"}],
    "stream": true
  }'
```

#### 任意兼容 OpenAI API 的客户端

只需修改 `base_url` 和 `api_key` 即可。例如 ChatBox、NextChat、OpenCat、CodeGPT 等桌面/Web 客户端，在设置中将 API Host 改为 `https://api.xiaoyekanren.com`，API 路径改为 `/openai/v1/chat/completions`。

### 2.3 Claude API / Anthropic SDK 兼容客户端

**base_url**：`https://api.xiaoyekanren.com/claude`
**api_key**：`<YOUR_API_KEY>`

#### Python (anthropic 库)

```python
import anthropic

client = anthropic.Anthropic(
    base_url="https://api.xiaoyekanren.com/claude",
    api_key="<YOUR_API_KEY>"
)

response = client.messages.create(
    model="gemini-2.5-pro",
    max_tokens=4096,
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.content[0].text)
```

#### Python (流式)

```python
with client.messages.stream(
    model="gemini-2.5-pro",
    max_tokens=4096,
    messages=[{"role": "user", "content": "Hello!"}]
) as stream:
    for text in stream.text_stream:
        print(text, end="")
```

#### cURL

```bash
curl -X POST https://api.xiaoyekanren.com/claude/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: <YOUR_API_KEY>" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "gemini-2.5-pro",
    "max_tokens": 4096,
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## 4. 安全建议

- **API_KEY 务必设强随机值**：`openssl rand -hex 32`
- **Cookie 保密**：`.env` 中的 `GEMINI_1PSID` 等同于 Google 账号密码，切勿泄露
- **限流保护**：默认每 60 秒最多 20 个请求，可在 `.env` 中调整 `RATE_LIMIT_MAX_REQUESTS`
- 如果仅自己使用，可在 nginx 中额外加 IP 白名单
